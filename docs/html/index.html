MatplotC

MatplotC é uma pequena biblioteca em C, inspirada no Matplotlib, para desenhar gráficos (linhas, dispersão, pizza, barras e histograma) usando a biblioteca gráfica raylib.

Uso básico

  1. Crie a janela com create_context().
  2. Crie as séries com create_data().
  3. Chame uma das funções de plotagem: plot_line(), plot_scatter(), plot_pie(), plot_bar() ou plot_histogram().

Durante a exibição, pressione a tecla S para salvar uma captura de tela em grafico.png. Feche a janela para encerrar a plotagem.

Exemplo

float x[] = {1, 2, 3, 4};
float y[] = {2, 4, 3, 5};
Context ctx = create_context(800, 600, "Meu grafico");
Data serie = create_data(plane, "Serie A", x, "Tempo", y, "Valor", 4);
plot_line(&ctx, &plane, &serie, 1);
