Context create_context ( float width,
float height,
const char * title )

Cria um contexto de janela validando os parâmetros.

Parâmetros
widthLargura da janela em pixels (deve ser maior que 0).
heightAltura da janela em pixels (deve ser maior que 0).
titleTítulo da janela (não pode ser NULL nem vazio).
Retorna
Contexto preenchido; ou um Context zerado se algum parâmetro for inválido (uma mensagem de erro é escrita em stderr).
Aviso
A string title não é copiada: ela precisa continuar válida enquanto o contexto for usado.
