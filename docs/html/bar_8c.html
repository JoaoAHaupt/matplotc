◆ draw_bar_data()

void draw_bar_data ( Data * data,
int data_count,
Plane * plane,
PlotArea * plot )

Desenha as barras de todas as séries dentro da área do gráfico.

A largura de cada grupo de barras é calculada a partir da menor distância entre dois valores consecutivos de x em qualquer série (ocupando 80% desse espaço). Dentro do grupo, cada série recebe uma barra de largura igual. As barras partem da linha de base y = 0 (limitada ao intervalo visível de y) e o desenho é recortado na área do gráfico.

Parâmetros
dataVetor de séries de dados.
data_countQuantidade de séries em data.
planePlano cartesiano com os limites de x e y.
plotÁrea de plotagem em pixels.
Observação
Não faz nada se algum ponteiro for NULL, se data_count for menor ou igual a zero ou se os limites do plano/área forem inválidos.
