◆ draw_hist_data()

void draw_hist_data ( Data * data,
int data_count,
Plane * plane,
PlotArea * plot )

Desenha as barras do histograma de cada série.

Os valores de x de cada série são distribuídos em classes (bins) de largura plane->scale_x entre os limites de x do plano. A altura de cada barra é a frequência (contagem) de valores na classe. Se o número de classes exceder a largura da área em pixels, ele é reduzido e a largura da classe é recalculada. A última classe inclui o limite superior de x. Com várias séries, as barras de cada classe são colocadas lado a lado.

Parâmetros
dataVetor de séries (apenas x é usado).
data_countQuantidade de séries em data.
planePlano cartesiano (limites de x/y e scale_x).
plotÁrea de plotagem em pixels.
Observação
Não faz nada se os parâmetros forem inválidos (ponteiros NULL, limites invertidos, scale_x não positivo ou não finito, etc.).
