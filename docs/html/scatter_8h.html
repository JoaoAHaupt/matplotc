Cria o gráfico de dispersão completo.

Desenha, em ordem: o plano (eixos e grade), os pontos, a reta de regressão (opcional), os rótulos dos eixos e a legenda.

Parâmetros
planePlano cartesiano.
dataVetor de séries de dados.
data_countQuantidade de séries em data.
plotareaÁrea de plotagem em pixels.
show_regressionSe verdadeiro, desenha a reta de regressão linear de cada série.

◆ draw_linear_correlation()

void draw_linear_correlation ( Data * data,
int data_count,
Plane * plane,
PlotArea * plot )

Desenha a reta de regressão linear (mínimos quadrados) de cada série.

Para cada série calcula y = a·x + b e traça a reta de x mínimo a x máximo do plano, na cor da série, com 1 px de espessura.

Parâmetros
dataVetor de séries de dados.
data_countQuantidade de séries em data.
planePlano cartesiano com os limites de x e y.
plotÁrea de plotagem em pixels.
Observação
Séries com menos de 2 pontos, ou com todos os x iguais (regressão indefinida), são ignoradas.
